# Brand

`mosaic-hero.jpg` is the README banner: an unfinished tessera field with one
tile not yet set. `mosaic-mark.jpg` is the square mark for avatars and social
previews.

The mark is wordless on purpose. Image models garble lettering, and Mosaic's
name belongs in type, not in the picture. Do not add slogans or UI chrome to
these files.

Meaning, if anyone asks: missing sockets are uncertainty; the hovering tile is
an intervention that has not been admitted; the gold grout line is a
verification thread, not a score.
