# Brand

The canonical mark is `mosaic-icon.svg`. Draw it on a 128 unit grid. Do not
trace photographs and do not ask an image model to letter the name.

| File | Use |
|------|-----|
| `mosaic-icon.svg` | Source of truth. README, GitHub avatar. |
| `mosaic-icon.png` | 1024 raster for hosts that will not take SVG. |
| `mosaic-og.svg` | 1280×640 social field, same mark centered. |
| `stills/` | Studio photographs. Not the product icon. |

## Construction

- Field `#17241e`, corner radius 28/128.
- Two outer columns of irregular quads (slate left, ink-blue right).
- A pale lintel across the top. A dark socket under it.
- Gold thread `#d4a84b` in the left grout: verification, not a score.
- Copper tile `#c45c38` rotated −17°, not seated in the socket. A small
  verdigris chip on the corner, not a diagonal flag.

At 16–32 px the mark should still read as: dark square, gold line, one
offset tile.

## Do not

- Add the word Mosaic inside the artwork.
- Center the floating tile.
- Replace the socket with a perfect circle or plus sign.
- Recolor to acid green, cream-and-serif terracotta, or pure black.
